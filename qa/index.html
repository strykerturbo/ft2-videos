How to use this after a code change

  1. Make the change.
  2. Run Smoke Tests (about a minute). If anything fails, open it from the report, fix the app, run smoke again.
  3. When smoke passes, commit / push.
  4. Now and then, Run Full QA and clear the "Needs a person" list. Before a major release, do the full run plus the manual checks on a real phone.

Not sure what to run? Tick the areas you changed above and use "Run tests for these areas". Results, notes and the last 30 runs are kept in this browser only.
