## Issues found
**Critical:** none.

**Major (failed):**
- **PR-005** - Print / Export. A 12-exercise session did not fit one Pocket page (content ran past the bottom). Root cause: my own earlier change that narrowed the title column left too little room. *Fixed.*
- **RS-001** - Custom Session Step 4 scrolled sideways at 320 px (+48 px) and 360 px (+8 px). Root cause: the exercise row (grip, thumbnail, name, minutes, replace, trash) was wider than the space beside the phase number. *Fixed.*

**Major (partial, not a bug):**
- **GN-013** - Generated-session coaching quality needs a person to read the samples.
- **GN-014** - Library coverage thin spots: Beat Players has 0 Rondos, Master the Ball has 0 SSGs, Defend Together / Win It Back have 1 Warmup, Win It Back has 1 SSG. A content gap in the sheet, not an app defect.
- **US-003** - (labelled Critical because it covers deleting data) Delete session, discard draft, delete template and abandon template edits all confirm correctly. The only gap: removing one exercise from a saved session is immediate with a toast, no confirmation or undo.

**Minor:**
- **P-009** (failed) - Saved data that is valid but the wrong shape (for example the draft's phase list stored as text) throws on startup and leaves a blank page. Unreadable data is handled fine. *Open.*
- Partials: BN-006 (Exercise Detail opened from the library or Home lights no bottom tab), ED-009 (needs a human look at the docked header), DI-013 (the live Apps Script answers the Valid Values request with the exercise list, so tag spellings could not be compared - the Valid Values route is probably not deployed), US-001 (14 screens have tap targets under 28 px: See all, favourite button, drag grips, the Add tags link ...), US-002 (icon-only buttons without a spoken name: bookmark, star, "more filters"), US-005 (text under 11 px, mostly small uppercase labels; the Session Setup field labels are 9 px), US-007 (unlabelled selects on Exercise Detail), RS-003 (low-contrast text, e.g. the "TA" avatar at 2.5:1).

**Polish:** H-012 (Home layout on a real phone, human check), CN-004 (yellow buttons in pop-up sheets have a 1 px light outline vs 1.5 px elsewhere), CN-006 ("Practice" still appears next to "Session": default session names, template names, "Building ... Practice").

## Known limits of this baseline
- Automated checks cannot judge looks, print quality on paper, share-sheet behaviour in Messages / WhatsApp, or generated-session quality - those are the 15 manual tests and the hybrid ones.
- Real-phone behaviour (iOS Safari, Home Screen mode, real clipboard / share sheet) was simulated, not exercised.
- Generator and data-integrity results reflect the Google Sheet as it was on 2026-10-18; the sheet changes independently of code commits.
- The coach's real saved sessions are never read by the suite (by design), so data-integrity checks cover generated and test-made sessions, not the live ones.
